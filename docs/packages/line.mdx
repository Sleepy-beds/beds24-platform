---
title: "beds24-line"
description: "LINE notifications for Beds24 booking events."
---

```bash
npm install @sleepy-beds/line
```

Send LINE notifications for new bookings, cancellations, and check-in reminders.

<Note>
  Uses the **LINE Messaging API**, not the discontinued LINE Notify (shut down March 2025).
  You need a Messaging API channel and its channel access token.
</Note>

## Quick start

```ts
import { Beds24LineNotifier } from "@sleepy-beds/line";

const line = new Beds24LineNotifier({
  channelAccessToken: process.env.LINE_CHANNEL_ACCESS_TOKEN!,
  to: process.env.LINE_GROUP_ID, // userId / groupId / roomId
});

await line.notify({
  event: "booking_created",
  booking: {
    guestName: "John Smith",
    checkIn: "2026-06-12",
    checkOut: "2026-06-14",
    guests: 2,
    totalPrice: 24000,
    phone: "090-1234-5678",
  },
});
```

## Events

| Event | Method |
| ----- | ------ |
| `booking_created` | `notifyBookingCreated(booking, to?)` |
| `booking_cancelled` | `notifyBookingCancelled(booking, to?)` |
| `checkin_reminder` | `notifyCheckinReminder(booking, to?)` |

## From a Beds24 booking

```ts
import { Beds24Client } from "@sleepy-beds/sdk";
import { Beds24LineNotifier, fromBeds24Booking } from "@sleepy-beds/line";

const arrivals = await client.getBookings({ arrivalFrom: tomorrow, arrivalTo: tomorrow });
for (const b of arrivals) {
  await line.notifyCheckinReminder(fromBeds24Booking(b, { propertyName: "古民家のらり" }));
}
```
