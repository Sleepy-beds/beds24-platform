# Examples

Runnable examples for the Beds24 developer platform. Each is a private workspace package
(not published). Build the packages first with `pnpm install && pnpm -r build` from the repo
root, then follow the example's own README.

| Example | Shows |
| ------- | ----- |
| [line-checkin-reminder](line-checkin-reminder) | Daily LINE reminder for tomorrow's arrivals (`@sleepy-beds/sdk` + `@sleepy-beds/line`). |

For a full Next.js booking flow, use [`@sleepy-beds/nextjs`](../packages/nextjs)
— its README has copy-paste App Router route handlers.
